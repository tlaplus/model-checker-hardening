# FuzzTLA

FuzzTLA tests the TLA<sup>+</sup> model checkers TLC and Apalache. It generates
TLA<sup>+</sup> specifications, checks each one with both tools, and records where
they disagree or fail.

This manual covers running FuzzTLA campaigns and analysing what they find. The
[README](../../README.md) explains how to build FuzzTLA.
